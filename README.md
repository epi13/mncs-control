# mncs-control

Machine-native control and dynamical-systems infrastructure for MNCS.

`mncs-control` pressures `mncs-language` with deterministic real-time loops, fixed-size linear algebra, state estimation, actuator/sensor boundaries, bounded execution and replayable system behavior.

## Initial scope

- state-space and dynamical-system models
- PID and foundational feedback controllers
- observers/estimators and filtering interfaces
- trajectory/reference handling
- model-predictive-control foundations
- sensor/actuator and simulation adapters
- real-time scheduling/deadline contracts
- deterministic replay and verification
